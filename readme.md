# Surfooo – Site vitrine de boutique de surf

## Présentation du travail

Ce projet consiste à réaliser un site vitrine responsive pour une boutique fictive appelée **Surfooo**, spécialisée dans la vente de planches de surf et d’accessoires.

---

## Ce qui a été fait

- **Page d’accueil complète** avec :
  - Bannière d’introduction
  - Liste de produits (planches et accessoires)
  - Section “Afficher plus” dynamique avec images
  - Effet **parallax scrolling**
  - Fenêtre modale pour agrandissement d’image
  - Section “Avis de nos clients”
  - Footer avec liens légaux et gestion des cookies
- **Design responsive** via media queries CSS
- **Gestion des cookies** avec `localStorage` + popup de consentement
- **Pages secondaires** : Contact avec formulaire, mentions légales et politique de confidentialité.

---

## Ce qui n’a pas été fait

- La pages secondaires plan_acces.html est présente mais pas remplie.
- Pas d’intégration avec base de données ni de backend.
- Pas de formulaire de contact fonctionnel.
